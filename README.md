# Excel Data Analysis Practice

This repository contains Excel practice exercises focused on data analysis, sorting, filtering, and spreadsheet operations.

## Topics Covered

- Data Sorting
- Data Filtering
- Date Operations
- Empty Cell Counting
- Employee Data Analysis
- Pokémon Dataset Analysis
- Customer Data Filtering
- Sales Data Analysis

## Practice Questions

### Q1
Suggestion charts for employee smoking policy.

### Q2
Worked with start date and end date operations.

### Q3
Counted empty cells in datasets.

### Q4
Filtered employees who joined before May.

### Q5
Sorted Pokémon data alphabetically and by attack speed.

### Q6
Filtered Pokémon records:
- Type = Poison
- Stage = 1 or 3

### Q7
Filtered Pokémon:
- Name starts with "C"
- Speed less than 80

### Q8
Filtered male customers with age greater than 22.

### Q9
Sorted territories and sales values.

### Q10
Filtered Job IDs:
- Starting with "F"
- Department ID greater than 50

### Q11
Checked whether dates fall between two dates.
